Parameters — definitions & expected values

Below are concise explanations of each input used by the model. Use these to ensure consistent data collection.

Age

Patient age in years. Typical adult range: 18–100. Higher age correlates with increased risk.

Sex

Binary: 1 = Male, 0 = Female.

Chest Pain (cp)

Categorical (common encoding used in cardiac datasets):

  • Yes — Have Pain
  • No — Don't have pain

Resting Blood Pressure (trestbps)

Measured in mm Hg. Use clinic resting value. Typical adult values: 90–180. Outliers should be validated.

Cholesterol (chol)

Serum cholesterol in mg/dl. Fasting lipid panel preferred. Abnormally high readings should be checked.

Fasting Blood Sugar (fbs)

Binary: 1 if fasting blood sugar > 120 mg/dl, else 0. Proxy for baseline glycemic status.

Max Heart Rate Achieved (thalach)

Maximum heart rate recorded during exercise testing or self-reported exertion. Lower values can reflect impaired cardiac reserve.

Exercise Induced Angina (exang)

Binary: 1 = yes (angina triggered by exercise), 0 = no.

Note: Ensure numeric fields are sent as numbers (not strings). Keep the same field names when calling the backend.

How the Model Works
Model overview

The model is a supervised classifier trained on clinical features to estimate the probability of significant coronary disease. It outputs a risk probability (0–1) which we display as a percentage.

Preprocessing
  1. Validate and impute missing values (prefer no missing values).
  2. Standardize numeric features (mean-variance scaling) using the same scaler as used in training.
  3. Encode categorical fields consistently (e.g., cp mapping shown earlier).
Model outputs

Primary output: probability of heart disease. Also provide a short textual interpretation:

  • <10% — Low risk (screening)
  • 10–30% — Moderate risk (consider further evaluation)
  • >30% — High risk (refer for clinical workup)
Explainability

For production, include local explanations (SHAP or LIME) so the clinician can see which features drove the prediction. Add confidence intervals when possible.

Safety note

This tool is for informational/screening use only and is not a substitute for clinical judgement.

About the Heart — short primer

What is the heart? The heart is a muscular organ that pumps blood through the body. Coronary arteries supply the heart muscle. When these arteries narrow, blood flow can be reduced leading to ischemia and chest pain.

Common risk factors: Age, male sex, hypertension, hypercholesterolemia, smoking, diabetes, family history.

Symptoms that matter: chest pain, breathlessness, syncope, palpitations. But some patients (especially diabetics) may have atypical or no chest pain (silent ischemia).

Clinical tests: ECG, exercise stress test, echocardiography, coronary CT/MRI, and invasive coronary angiography for diagnosis.
